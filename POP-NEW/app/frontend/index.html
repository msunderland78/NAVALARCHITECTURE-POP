How POP for the Web computes a design

Open-water polynomial

Thrust and torque coefficients KT and KQ are evaluated from the 39-term and 47-term polynomials in Bernitsas, Ray, Kinley (1981), Tables I and II, which reproduce Oosterveld and van Oossanen (1975). Inputs must lie inside the published valid range for J, P/D, Ae/Ao, and blade count Z in [3, 7]. The implementation never extrapolates outside that domain.

Reynolds correction

The base polynomial is reported at RN_ref = 2 x 10^6. A second polynomial in log10(RN / 2 x 10^6), taken verbatim from Oosterveld and van Oossanen (1975), shifts KT and KQ to the operating Reynolds number. The sectional RN is estimated from the 0.75R tangential speed and a representative chord c_0.75R = 2.073 * Ae/Ao * D / Z following Carlton (2012). This puts our reported RN about 7% below the legacy POP-1.5 fitted value but generalises to any blade count and area ratio.

Cavitation constraint

The Burrill back-cavitation criterion is a digitised lookup of the 5% and 10% allowable thrust-loading lines from Carlton (2012), Figure 9.21, with linear interpolation in sigma_0.7R and linear blending between the two lines for intermediate cavitation percentages. Designs whose loading exceeds the allowable line are rejected from the optimum search.

Optimization

In Optimization mode the search sweeps Z in {3, 4, 5, 6, 7}. For each Z a three-phase grid search over (D, P/D, Ae/Ao) with 9 x 9 x 9 candidates per phase narrows around the previous-phase best. At every candidate the advance coefficient J is solved by a 20-iteration bisection so predicted thrust matches required thrust. The result panel shows both the global best and a per-Z table so blade-count selection becomes an output, not a separate user decision.

Controllable pitch

When Pitch Type is Controllable the open-water efficiency is multiplied by 0.98 as an empirical hub-loss allowance carried over from POP-1.5. This is not a physical CPP hub-loss model. Real CPP hub losses depend on hub-to-diameter ratio and blade root section.

Calibration status

The implementation is locked against transcription error by regression tests that pin landmark coefficients, the Reynolds correction at the NA 470 sample point, and each digitised Burrill chart node. See analysis/wageningen-b-series-sources.md in the repository for the full citation list and the test names. POP for the Web is a preliminary design tool. Final propeller drawings, class approval, or model-test correlation remain out of scope.
